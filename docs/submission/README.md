# Bộ sản phẩm nộp

P2 tổng hợp; mỗi người tự giao phần mình. Checklist cuối kỳ theo tài liệu môn:

- [ ] Repo có hướng dẫn chạy và lịch sử đóng góp cá nhân.
- [ ] Backend public và endpoint health chạy thật.
- [ ] APK release Android Admin cài trên máy thật.
- [ ] APK release Flutter Client cài trên máy thật.
- [ ] Báo cáo PDF 20–35 trang, đủ 9 phần và ít nhất 25 ca kiểm thử thực tế.
- [ ] Video demo thật 5–8 phút có thuyết minh.
- [ ] Tài khoản thử cho từng vai trò, dùng riêng cho demo.
- [ ] Bảng phân công có tỷ lệ và xác nhận/chữ ký theo đề.

Ghi vị trí nhận sản phẩm trong `artifacts.md`. Không đánh dấu đạt trước khi kiểm; hiện sườn chỉ chuẩn bị chỗ lưu.
