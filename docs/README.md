# Tài liệu dự án

| Nội dung | Đặt ở đâu | Người tổng hợp |
|---|---|---|
| Vị trí code và người phụ trách | `OWNERSHIP.md`, `structure.md` | P2; P1 review kỹ thuật |
| Cách dùng GitHub | `github-workflow.md` | P2 |
| Hợp đồng chung | `contract-v1.md` | P1 + P2; P3/P4 review |
| Đặc tả API | `openapi.yaml`, `api.md`, `examples/` | P1 tổng hợp; P2 viết API nghiệp vụ |
| Nghiệp vụ | `business-rules.md`, `decisions.md` | P2 |
| ERD và từ điển dữ liệu | `erd.md`, `design/erd/` | P1 tổng hợp; P2 bổ sung |
| Use case | `design/use-cases/` | P2 tổng hợp; cả nhóm góp |
| Wireframe và ảnh màn hình | `design/wireframes/admin/`, `client/`; `design/screenshots/` | P3/P4 |
| Kế hoạch, phân công, backlog | `planning/` | P2 điều phối; mỗi người viết phần mình |
| Bộ dữ liệu demo có định danh chung | `fixtures/` | P1 tổng hợp; P2 tạo tình huống nghiệp vụ |
| Kiểm thử và bằng chứng | `testing/` | Mỗi người tự ghi; P2 tổng hợp |
| Deploy | `deployment/` | P1; P2 phụ trách nội dung job |
| Báo cáo | `report/` | Mỗi người viết phần mình |
| Kịch bản demo | `demo/` | Cả nhóm |
| Danh mục sản phẩm nộp | `submission/` | P2 |

Giữ một bản áp dụng chung cho API/ERD/nghiệp vụ. Trong Issue/PR, ghi phiên bản hoặc commit tài liệu đang dùng. Các file nháp trong sườn này chưa chứng minh chức năng đã chạy.
