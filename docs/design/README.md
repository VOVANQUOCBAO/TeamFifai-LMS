# Thiết kế hệ thống và giao diện

| Thư mục | Nội dung | Người tổng hợp |
|---|---|---|
| `use-cases/` | Sơ đồ use case và mô tả 5–7 luồng quan trọng | P2, cả nhóm góp |
| `erd/` | Bản nguồn ERD, bản xuất và từ điển dữ liệu | P1/P2 |
| `wireframes/admin/` | Luồng thủ thư và ADMIN | P3 |
| `wireframes/client/` | Luồng bạn đọc | P4 |
| `screenshots/admin/`, `screenshots/client/` | Ảnh màn hình thật khi app đã có | P3/P4 |

Đặt tên có nội dung như `loan-return-flow.mmd`, `library-erd.drawio`, `admin-loan-wireframe.png`. Phân biệt wireframe với ảnh app chạy thật. Ghi phiên bản hoặc commit thiết kế đang áp dụng trong PR.
