# Báo cáo cuối kỳ

Mỗi người viết phần mình trong `sections/`; nhóm trưởng tổng hợp. Bản xuất cuối đặt trong `exports/`.

| Mục báo cáo theo đề | Người cung cấp nội dung |
|---|---|
| 1. Giới thiệu | P2 tổng hợp, cả nhóm góp |
| 2. Phân tích yêu cầu | P2; P3/P4 góp luồng app |
| 3. CSDL | P1/P2 |
| 4. API | P1/P2 |
| 5. Giao diện | P3/P4 |
| 6. Triển khai | P1; P2 góp job |
| 7. Kiểm thử | Mỗi người cung cấp kết quả phần mình |
| 8. Phân công và tiến độ | Mỗi người cung cấp bằng chứng, P2 tổng hợp |
| 9. Tự đánh giá | Cả nhóm |

Yêu cầu cuối kỳ theo nguồn: PDF 20–35 trang, tối thiểu 25 ca có kết quả thực tế. Đây là vị trí lưu, chưa có báo cáo hoàn chỉnh. Có thể đặt file `p1-platform.md`, `p2-circulation.md`, `p3-android.md`, `p4-flutter.md` khi bắt đầu viết.
