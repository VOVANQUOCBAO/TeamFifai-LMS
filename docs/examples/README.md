# JSON mẫu cho hai app

P1/P2 đặt request/response mẫu sau khi chốt schema. Gợi ý tên: `auth-login.response.json`, `catalog-list.response.json`, `loan-create.request.json`, `loan-return.response.json`, `reservation-list.response.json`, `error-conflict.response.json`.

Dùng dữ liệu giả, null và kiểu giống hợp đồng. Không lưu token hoặc mật khẩu thật. P3/P4 dùng chung mẫu để viết model và mock repository; mẫu không chứng minh API đã chạy.
